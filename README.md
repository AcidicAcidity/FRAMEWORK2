# Система совместного использования автомобилей

## Назначение
Приложение представляет собой платформу для каршеринга (совместного использования автомобилей). Основная задача — предоставить владельцам возможность сдавать свои автомобили в краткосрочную аренду, а пользователям — быстро находить и бронировать машину для поездки.

## Целевая аудитория
- Владельцы автомобилей: пользователи, желающие сдавать свой автомобиль в аренду и получать доход.
- Пользователи (арендаторы): люди, которым нужен автомобиль на короткое время без покупки собственного.
- Администраторы сервиса: сотрудники, контролирующие состояние автомобилей и поездок.

## Предметная область
Сервисы краткосрочной аренды транспортных средств (каршеринг), платформы совместного потребления (sharing economy). Область охватывает процессы регистрации автомобилей, поиска доступных машин, оформления поездок и расчёта их стоимости.

## Основные сущности
- Автомобиль: транспортное средство (марка, модель, номер, стоимость аренды за час).
- Владелец: пользователь, который предоставляет автомобиль в аренду.
- Пользователь (арендатор): пользователь, который бронирует и использует автомобиль.
- Поездка: факт аренды автомобиля (дата, длительность, стоимость, участники).

## Основные функции
- Регистрация автомобиля владельцем.
- Проверка доступности автомобиля для аренды.
- Расчёт стоимости поездки в зависимости от длительности.
- Оформление поездки пользователем.

## План развития
На следующих этапах планируется:
- разработка веб-приложения;
- подключение базы данных;
- реализация пользователей;
- разработка API;
- контейнеризация приложения;
- настройка CI/CD.
