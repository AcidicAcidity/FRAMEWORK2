# Система совместного использования автомобилей

Консольное приложение для каршеринга: владельцы регистрируют автомобили,
пользователи оформляют поездки. Данные хранятся в JSON-файлах.

## Назначение
Платформа каршеринга (совместного использования автомобилей). Владельцы
сдают автомобили в краткосрочную аренду, пользователи быстро находят и
бронируют машину для поездки.

## Целевая аудитория
- Владельцы автомобилей — сдают автомобиль в аренду и получают доход.
- Пользователи (арендаторы) — берут автомобиль на короткое время.
- Администраторы сервиса — контролируют автомобили и поездки.

## Предметная область
Сервисы краткосрочной аренды транспортных средств (каршеринг), платформы
совместного потребления (sharing economy): регистрация автомобилей,
поиск доступных машин, оформление поездок и расчёт их стоимости.

## Возможности
- просмотр, поиск, фильтрация (по цене) и сортировка автомобилей;
- регистрация автомобиля владельцем;
- проверка доступности автомобиля на дату;
- расчёт стоимости поездки со скидкой за длительную аренду
  (5% — от 6 часов, 15% — от 24 часов);
- оформление и отмена поездок (на одну дату автомобиль можно взять
  только один раз);
- статистика (число автомобилей, поездок, выручка);
- хранение данных между запусками в JSON-файлах.

## Структура проекта
- `main.py` — точка запуска, меню и пользовательские сценарии;
- `cars.py` — функции работы с автомобилями;
- `trips.py` — функции работы с поездками (доступность, цена, отмена);
- `storage.py` — загрузка и сохранение данных (JSON, `with`, исключения);
- `utils.py` — безопасный ввод данных и вспомогательные функции;
- `data/` — JSON-файлы данных (`cars.json`, `trips.json`);
- `tests/` — автоматизированные тесты (pytest).

## Формат данных
`data/cars.json` — список словарей: `id`, `brand`, `model`, `number`,
`owner`, `price_per_hour`, `is_available`.

`data/trips.json` — список словарей: `id`, `car_id`, `user`,
`trip_date` (`ГГГГ-ММ-ДД`), `hours`.

- Python 3.9+;
